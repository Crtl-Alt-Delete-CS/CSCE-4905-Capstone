# Crtl-Alt-Delete-Project

How to set up 

1. Install Unity Hub. Make sure the version is correct (6000.6.3f1)
2. Include android build support and android SDK modules
3. Install Git LFS (git lfs install)
4. Clone the repository
5. In terminal in the cloned repository folder use git lfs pull
6. In unity hub add the project from disk (select the folder containing the assets and project settings)
7. In unity hub click on project to launch
8. Select the correct scene in the scene folder
9. Hit play to run AR environment
